# French Electricity Consumption AESA Case Study over the period 2019--2060

Reference article:

de Bantel, E. I., Pirson, T., Puig-Samper, G., Hartmann, J. M., Bouillass, G.,
Yannou, B., Jankovic, M., Bol, D., & Hauschild, M. Z.
UNCASExt -- A Systematic Computational Framework for Uncertainty Propagation and
Scope Consistency in Absolute Environmental Sustainability Assessments (AESA)
[Manuscript submitted for publication].

Software:

- pyaesa v1.2.4

LCIA methods:

- PB-LCIA
- GWP100

## LCA Result Source CSV Files

The LCA results can be reproduced via
[oie-mines-paristech/RTE_scenarios](https://github.com/oie-mines-paristech/RTE_scenarios)
following the method described in de Bantel et al. (2026).

`lca/rte_lca_historical_2019_2025.csv`

Historical LCA result table for 2019 to 2025. The LCA uncertainty notebook
uses this file as the historical source when it builds compact external LCA
Monte Carlo inputs for pyaesa.

`lca/rte_lca_prospective_2026_2060.csv`

Prospective LCA result table for 2026 to 2060. The LCA uncertainty notebook
uses this file as the prospective source when it samples IAM model-scenario
pairs and writes the compact external LCA Monte Carlo inputs used later by
pyaesa for ASR computations.

## Impact Per Process CSV Files (unused for AESA results)

`lca/lca_per_process/2019_lca_technos.csv`

2019 impacts per process table. It contains the historical per process
LCA contribution and intensity values.

`lca/lca_per_process/2060_lca_technos_per_iam.csv`

2060 impacts per process table by IAM model-scenario pair. It contains per
process contribution and intensity values.

`lca/lca_per_process/2060_lca_technos_stats.csv`

2060 impacts per process summary table. It contains the summary statistics after 
IAM model-scenario pairs have been drawn by `rte_lca_uncertainty.ipynb`.

## Jupyter Notebooks

`rte_lca_uncertainty.ipynb`

Phase A notebook for the ASR numerator. It uses the historical and prospective
LCA result CSV files to generate the compact external LCA Monte Carlo run
files required by pyaesa ASR uncertainty computations.

`rte_asr_uncertainty.ipynb`

Phase B and Phase C notebook for pyaesa AESA results. It prepares the ASR
denominator, then computes ASR uncertainty results using the external LCA
Monte Carlo sources generated by `rte_lca_uncertainty.ipynb`.

## Run Order

1. Run `rte_lca_uncertainty.ipynb` to stage the external LCA Monte Carlo inputs.
2. Run `rte_asr_uncertainty.ipynb` to compute the pyaesa AESA results.
